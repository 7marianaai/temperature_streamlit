# Анализ температуры и мониторинг текущей погоды

Проект для анализа температурных временных рядов. Приложение помогает изучать сезонные различия, находить необычные значения температуры и сравнивать текущую погоду с историческим диапазоном выбранного города.

## Что можно делать в приложении

- Использовать готовый набор данных или загрузить свой CSV.
- Выбрать город из выпадающего списка.
- Посмотреть описательную статистику: среднее, стандартное отклонение, минимум, максимум и квартили.
- Изучить временной ряд температур и скользящее среднее за 30 дней.
- Переключаться между сезонными аномалиями и аномалиями относительно скользящего окна, увидеть их на графике и в таблице.
- Сравнить средние температуры сезонов и их разброс.
- Посмотреть годовые средние температуры и линию долгосрочного тренда.
- Получать текущую температуру автоматически с ключом OpenWeatherMap из локального файла или ввести ключ в интерфейсе и проверить, находится ли температура в пределах сезонной нормы.

Все графики интерактивные: можно приближать участки, смотреть значения при наведении и скрывать отдельные ряды через легенду.

## Данные и их генерация

Файл `temperature_data.csv` содержит **синтетические данные**: 54 750 строк по 15 городам. Для каждого города сгенерировано 3 650 ежедневных значений с 1 января 2010 года по 29 декабря 2019 года.

Генератор находится в `dz_1.ipynb`. Для каждого города заранее заданы примерные средние температуры зимы, весны, лета и осени. Для каждой даты определяется сезон, затем температура случайно выбирается из нормального распределения:

```python
temperature = np.random.normal(loc=mean_temp, scale=5)
```

Здесь `mean_temp` — заданная средняя температура города для сезона, а `5` — стандартное отклонение в °C. Полученные значения используются как среднесуточные температуры и сохраняются в CSV.

Особенности набора:

- Значения генерируются независимо по дням. Плавная смена сезонов и связь погоды соседних дней не моделируются; на границах сезонов возможны резкие переходы.
- Долгосрочное потепление или похолодание в генератор не заложено. Наклон линии тренда может появляться из-за случайных колебаний и состава наблюдений.
- Календарь сезонов одинаков для всех городов: декабрь–февраль — зима, март–май — весна, июнь–август — лето, сентябрь–ноябрь — осень. Для Сиднея и Рио-де-Жанейро сезоны не переворачиваются, поэтому набор упрощает реальные климатические условия.
- Параметр `num_years=10` задаёт `365 * 10` дней, поэтому период немного короче десяти полных календарных лет из-за високосных дней.

## Как определяются аномалии

Есть два способа:

- **Сезонный:** температура сравнивается со средним и стандартным отклонением для этого города и сезона по всем историческим годам.
- **По скользящему окну:** среднее и стандартное отклонение рассчитываются по текущему и 29 предыдущим дням. В первые 29 дней полного окна ещё нет, поэтому эти показатели не определяются.

Аномалией считается значение за пределами **среднего ± 2 стандартных отклонения**. Значения на самих границах относятся к нормальным. На графике сезонного профиля отдельно показаны средние с разбросом **± 1 стандартное отклонение**.

Текущая температура из OpenWeatherMap сравнивается с исторической сезонной нормой; сезон определяется по местному времени данных о погоде. Это учебное сравнение: API возвращает температуру на конкретный момент, а исторический набор содержит искусственные среднесуточные значения. Полученный статус не является выводом об изменении климата.

## Формат своего CSV

| Столбец | Содержание |
|---|---|
| `city` | Название города, например `Moscow` |
| `timestamp` | Дата, например `2010-01-01` |
| `temperature` | Среднесуточная температура в °C |
| `season` | `winter`, `spring`, `summer` или `autumn` |

Для каждого города нужна одна строка на день без пропусков дат и повторов. В обязательных столбцах не должно быть пустых значений; даты и температуры должны быть корректными, а сезоны — соответствовать календарю генератора. Порядок строк может быть любым: приложение сортирует их по городу и дате.

Если для текущего сезона нет исторических данных или есть только одно наблюдение, приложение покажет погоду и сообщение о невозможности оценить сезонную норму.
